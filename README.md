# Proj_NextGen_Customer_Service_Agent
### About: 
This project demonstrates how Retrieval-Augmented Generation (RAG) can be applied to build an intelligent chatbot that leverages both unstructured data (PDF product manuals) and structured data (Product, Policy, Customer records). The chatbot is capable of answering queries about product specifications, available policies, and customer order history by combining multiple knowledge sources.
